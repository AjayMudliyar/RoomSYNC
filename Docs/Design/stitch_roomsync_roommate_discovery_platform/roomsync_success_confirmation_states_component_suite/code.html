Design System Standards

Engineering & UX Principles for Confirmation Systems

In roommate search and urban relocation, premature certainty breeds mistrust. Our state engine enforces strict integrity guidelines across all Indian metro platforms.

balance

1. Bilateral State Honesty

Explicitly delineate one-way submissions from mutual consents. Handshake invitations must never be displayed as accepted until the counterparty explicitly verifies.

warning

2. Non-Premature Guarantees

Property visit requests and KYC uploads are categorized as pending reviews. The UI prohibits terminology like "Confirmed Booking" or "Verified Badge" prior to actual SLA completion.

history

3. Reversible Governance

Account deletions enforce a 30-day reversible window compliant with DPDP Act 2023. Users receive explicit timelines and frictionless single-click restoration options.

devices

4. Cross-Platform Parity

Tailwind CSS tokens map 1:1 to React Native StyleSheet objects. Buttons ensure 44px minimum tap targets with accessibility labels calibrated for TalkBack and VoiceOver.
